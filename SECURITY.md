# Security

Never paste bot tokens, API keys, or other secrets into an issue, a comment, or a commit. If a token has leaked, revoke it with BotFather and create a new one.

A bug that skips outbound scrubbing, ignores the chat allowlist, or leaks a token is a security problem. Report it privately via the Security tab of this repository (Advisories), not in an open issue. Say the version and the MCP client. Do not include secrets.
